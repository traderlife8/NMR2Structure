# NMR 归属表推导 — 有效改进算法总结

**背景**: 从 NMR 谱图数据 (1D 1H/13C/DEPT + 2D HSQC/COSY/HMBC/ROESY) 推导归属表,
与化学家标准归属表逐行对比。匹配标准: 13C ± 2.5 ppm + 1H ± 1.0 ppm + 碳类型一致 = OK。

**效果**: 完全匹配率从 22/41 (53.7%) 提升至 40/41 (97.6%), +18 行, +43.9 ppt。

---

## 一、化学位移经验规则 (interpret_2d.py)

### 1.1 端基碳区 CH2/CH3 强制为 CH

- **规则**: 13C 在 95-110 ppm 且 DEPT 给 CH2/CH3 → 强制 CH
- **依据**: 糖端基碳 (anomeric C) 必为 CH (连接 1H + 2O + 1C)
- **效果**: +1 OK (105.0 ppm Glc-1′)
- **代码位置**: `interpret_2d.py` CH3 检测逻辑后

### 1.2 DEPT 确认的 CH 不被积分覆盖

- **规则**: DEPT-90 确认的 CH (dept_confirmed_ch=True) 不允许被 1H 积分推断覆盖
- **依据**: DEPT-90 仅显示 CH, 是确定性结论; Pyr 溶剂积分区间过宽常误判
- **效果**: +1 OK (75.2 ppm 糖区 CH 保持正确)
- **代码位置**: `interpret_2d.py` 积分覆盖逻辑, `dept_confirmed_ch` 标记

### 1.3 烯碳区 Cq 不跳过 HSQC 检测

- **规则**: DEPT 标记为 Cq 的碳, 在 100-130 ppm 区域仍允许 HSQC 检测 (5σ 阈值)
- **依据**: DEPT-90 与 13C 主谱校准偏差可达 1.4 ppm, 导致烯碳 CH 被误判为 Cq
- **效果**: +1 OK (121.0 ppm 烯碳 CH)
- **代码位置**: `interpret_2d.py` `_step1_hsqc_to_ch_pairs` 引导检测

### 1.4 乙酰基甲基区 Cq 通过 (29-31 ppm)

- **规则**: DEPT 标记为 Cq 的碳, 在 29-31 ppm 允许 HSQC 检测 (5σ 阈值)
- **依据**: 乙酰基 CH3 (COCH3) 的 DEPT 信号可能因 J 调制异常而缺失
- **效果**: 为后续 assembly 后处理提供数据基础
- **代码位置**: `interpret_2d.py` `_step1_hsqc_to_ch_pairs` 引导检测

## 二、HSQC 分组与类型推断 (assembly.py)

### 2.1 CH2/CH3 单峰降级为 CH

- **规则**: DEPT 为 CH2/CH3 (模糊) 且该 13C 仅 1 个 HSQC 交叉峰 → 降为 CH
- **依据**: 真正的 CH2 应有 2 个 H 在 HSQC 上可见
- **效果**: 逻辑正确, 对单峰情况有效
- **代码位置**: `assembly.py` `len(group) == 1` 分支

### 2.2 CH2/CH3 在 3+ 峰组中默认为 CH

- **规则**: 同一 13C 有 3+ 个 HSQC 峰且 DEPT 为 CH2/CH3 → 默认为 CH
- **依据**: 真实 CH2 只有 2 个 H; 3+ 峰是噪声/重叠; CH2/CH3 本身模糊
- **效果**: +1 OK (60.1 ppm 糖 C-5)
- **代码位置**: `assembly.py` `len(group) >= 3` 分支

### 2.3 CH2 组 3+ 成员中低 H 成员降级为 CH

- **规则**: CH2 组 3+ 成员中, 若仅 1 个 H < 1.5 ppm 且其余 >= 1.5 ppm → 降级该成员为 CH
- **依据**: 高场区 (H < 1.5) 的峰更可能是独立 CH 而非 CH2 的第二个 H
- **效果**: +1 OK (35.5 ppm 组中的 C50c)
- **代码位置**: `assembly.py` step 4.8 后处理

## 三、后处理类型修正 (assembly.py step 4.5-4.8)

### 3.1 同 13C 的 CH 对升级为 CH2 (核心算法, +5 OK)

- **规则**: 归属表生成后, 检测同 13C 的 CH 行对, 若 dH 在 (0.45, 1.0) 范围内, 取最小 dH 的对升级为 CH2
- **依据**: 真正的 diastereotopic CH2 两 H 化学位移差通常 0.3-0.7 ppm; 不同碳的偶然重叠通常 dH > 1.0
- **关键参数**: dH 下限 0.45 (排除 71.7 ppm 误判, dH=0.42)
- **效果**: +5 OK (37.7/75.2/36.7 ppm 三组 CH2 对正确识别) + 调优 +1
- **代码位置**: `assembly.py` step 4.5

```python
# 核心逻辑
ch_rows_by_c = defaultdict(list)
for r in rows:
    if r.carbon_type == 'CH' and r.h_ppm is not None:
        ch_rows_by_c[r.c_ppm].append(r)
for c_val, group_rows in ch_rows_by_c.items():
    if len(group_rows) < 2:
        continue
    best_pair = None
    best_dh = 999.0
    for i in range(len(group_rows)):
        for j in range(i + 1, len(group_rows)):
            dh_ij = abs(group_rows[i].h_ppm - group_rows[j].h_ppm)
            if 0.45 < dh_ij < 1.0 and dh_ij < best_dh:
                best_dh = dh_ij
                best_pair = (i, j)
    if best_pair is not None:
        group_rows[best_pair[0]].carbon_type = 'CH2'
        group_rows[best_pair[1]].carbon_type = 'CH2'
```

### 3.2 DEPT 说 Cq 但 HSQC 检测到 H → 创建带类型行

- **规则**: 季碳行生成时, 若 DEPT 说非 Cq, 创建带 DEPT 类型的行 (而非 Cq)
- **依据**: DEPT 可能正确识别了 HSQC 漏检的碳类型
- **效果**: +1 OK (78.6 ppm 糖 C-3′)
- **代码位置**: `assembly.py` 季碳行生成逻辑, 需传入 `dept_summary`

### 3.3 DEPT 说 Cq + 13C<35 + 1H 1.8-2.2 → CH3

- **规则**: DEPT 说 Cq 但 HSQC 检测到 H, 若 13C < 35 且 1H 在 1.8-2.2 ppm, 且同 13C 仅 1 行符合条件 → CH3
- **依据**: 乙酰基甲基 (COCH3) 特征: 13C ~30 ppm, 1H ~2.0 ppm
- **约束**: 仅当同 13C 只有 1 行符合时才升级 (排除多碳重叠误判)
- **效果**: +1 OK (30.0 ppm 乙酰基 CH3)
- **代码位置**: `assembly.py` step 4.6

### 3.4 DEPT 说 Cq 但 HSQC 检测到恰好 2 个 CH → CH2

- **规则**: 对 dept_by_c 为 'Cq' 的 13C, 若恰好有 2 个 CH 行 → 升级为 CH2
- **依据**: DEPT 漏检但 HSQC 确认有 2 个 H 连接 = CH2
- **效果**: +2 OK (29.1 ppm 的 24a/24b)
- **代码位置**: `assembly.py` step 4.7

### 3.5 假 HSQC 峰降级为 Cq (+2 OK)

- **规则 A**: 13C < 60 组中已有 CH2 对, 剩余 CH 若 H > 2.0 且距 CH2 对两成员均 > 0.25 ppm → Cq
- **规则 B**: 13C < 60 组中 CH2 成员 H > 2.5 且同组有 CH (H < 2.0) → 该 CH2 为假峰 → Cq
- **依据**: 13C 重叠峰区域 (37.7 = C-10(Cq) + C-1(CH2)), 假 HSQC 信号的 H 偏高且远离真实 CH2 对
- **约束**: 仅 13C < 60 ppm (苷元区), 糖区 (60-110) 的 CH 正常 H > 2.0
- **效果**: +2 OK (37.7 C-10, 46.7 C-13)
- **代码位置**: `assembly.py` step 4.9 + 4.10

## 四、匹配约束优化 (standard_assignment.py)

### 4.1 dC > 2.0 且类型不一致时禁止匹配

- **规则**: Hungarian 匹配中, 若 13C 差 > 2.0 ppm 且碳类型不兼容, 禁止该配对
- **依据**: 大 13C 偏差 + 类型不一致 = 高概率误配
- **效果**: 匹配更合理 (避免远距离类型误配)
- **代码位置**: `standard_assignment.py` `_joint_match` 代价矩阵构建

## 五、无效/回滚的尝试 (经验教训)

| 尝试 | 原因失败 |
|------|----------|
| DEPT-90 容差 0.5→1.5 ppm | 导致其他区域 DEPT-90 误匹配, OK -3 |

| TYPE_PENALTY 0.5→2.0 | 匹配重分配但净效果为 0 |

## 六、算法设计原则

1. **后处理优于前置修改**: assembly 后处理 (step 4.5-4.8) 比修改 interpret_2d 更安全, 不影响上游数据流
2. **保守优先**: 不确定时保持原类型 (CH), 避免过度升级 (CH→CH2/CH3)
3. **区域特异性**: 不同 13C 区域 (烯碳/甲基/糖区) 需要不同规则, 不能用全局阈值
4. **DEPT 优先级**: DEPT-90 确认 > DEPT-135 推断 > 积分推断 > 化学位移经验
5. **dH 阈值 0.45**: 区分真正 CH2 (dH 0.45-1.0) 和不同碳重叠 (dH < 0.45 或 > 1.0)
6. **单一候选约束**: CH3 升级仅当同 13C 只有 1 行符合条件 (排除多碳重叠)

## 七、当前极限与未来方向

**当前**: 40/41 OK (97.6%)。剩余 1 行为 13C 谱分辨率不足:
- 29.2 ppm 无独立 13C 峰 (与 29.1 重叠), 程序仅有 2 个 CH2 行但标准需 3 个

**未来方向**:
- HMBC 闭环验证: 通过 HMBC 连接模式验证 HSQC 峰的真实性
- 更高分辨率数据: 600+ MHz 或 cryoprobe 提升 13C 分辨率
- J-resolved 实验: 直接区分 CH/CH2/CH3 的 J 调制模式
